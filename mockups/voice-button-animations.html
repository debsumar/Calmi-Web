Rumi voice button — animation options

Six candidate treatments for the voice control in the chat composer, sitting in a replica of the real composer row. Tap any button to toggle its listening state. There is no voice model behind these — the amplitude ring fakes its input with a random walk.

Option 1

Pulsing halo

Soft brand ring scales out and fades on a 1.5s loop, two staggered waves. Same ripple vocabulary as the topbar ink indicator. Cheapest to build, reads instantly.

State: idle

Option 2 · recommended

Live waveform bars

Icon becomes five bars with staggered height animation — closest to ChatGPT voice mode. Reuses the staggered-dot pattern already in chat-typing.component.ts.

State: idle

Option 3

Icon morph to stop

Waveform glyph rotates out, rounded stop square rotates in, button fills brand. Communicates tap-to-stop rather than only signalling state. Composes with 1 or 2.

State: idle

Option 4

Breathing mascot

Rumi logo scales 1 → 1.09 on a slow 2.4s ease. Echoes the existing logo-pulse on the chat bubble. Calmest, most on-brand; weakest as a pure "recording" signal.

State: idle

Option 5

Composer-wide listening state

Textarea is replaced by a "Listening…" strip with hopping dots and a cancel action. Unmistakable modal state, and a natural home for partial transcripts once the model lands.

Listening…

State: idle

Option 6

Amplitude-reactive ring

Ring scale is driven by input level. Here it is a random walk; the real version needs an AnalyserNode, so it only pays off once the voice model exists.

State: idle

Notes — the glyph used throughout is Lucide audio-lines, already registered in app.config.ts, not a mic: a mic implies dictation into the text box, a waveform implies a spoken conversation. Colours are copied from src/tailwind.css so nothing here introduces a new value. Every variant has a static reduced-motion fallback — toggle the checkbox above to check it. Suggested combination: option 2 for listening, option 3 for the stop affordance, option 4 reserved for when Rumi is speaking back, giving three visually distinct states.
