Illustration backgrounds

Eight still line illustrations in the same family as the contour prototype. None of them animate, so all eight cost nothing at runtime and render identically on every device. Each is one inline SVG on a layer behind the cards, stroked with a single token so it flips with the colour scheme. Use Hide cards to judge the artwork on its own, and Stronger opacity to see how far each can be pushed before it competes with the numbers.

Baseline

The original prototype. Reads as landscape and terrain, calm without being literal about wellbeing. Safe on every card layout because the lines are horizontal and never crowd a corner.

Implementation notes

  • Every illustration is stroked with one variable, --art, and one opacity, --art-opacity. In Angular that becomes a token pair so the artwork flips with .app-dark instead of carrying a second copy of the palette.
  • The dark scheme needs its own opacity. A stroke that reads correctly at 28 percent on the light canvas is too faint at the same value on the dark one, which is why I6 in particular sets a different value per scheme.
  • The layer is aria-hidden, pointer-events:none, negative z-index inside an isolate container. Purely decorative, never in the accessibility tree.
  • vector-effect: non-scaling-stroke keeps line weight constant when the SVG is stretched, so the art does not thicken on wide screens.
  • Pick preserveAspectRatio deliberately: slice for art that should crop and fill, xMidYMax slice for anything anchored to the bottom such as I4 and I5, and none only where stretching is harmless as in I3.
  • These add no runtime cost, but they do add DOM. Inline the chosen one as a component template rather than repeating it per card, and keep it to a single instance per page.
  • Contrast is unaffected because the art never sits under text: cards stay opaque. If a card is ever made translucent, re-measure body text against the composited result.
