Profile background prototypes

Six ambient treatments behind the same three bento cards. Every one is built from the Calmi palette, sits on its own layer behind the content, is inert to pointer and screen reader, and animates transform or opacity only so it never triggers layout. Use the two buttons above to check both colour schemes and to confirm each prototype degrades to a still image, which is exactly what prefers-reduced-motion: reduce does.

P1 - Aurora blobs

Most atmosphere, highest cost

Three large blurred radials drift on independent 26 to 38 second loops. Feels alive and on-brand. The blur is the expensive part: keep the count at three, never animate the blur itself, and expect a repaint cost on low-end mobile.

P5 - Focused card halo

Most targeted

The page background stays flat and only the featured card carries a soft pulsing halo. Guides attention to the allowance that matters instead of decorating everything, and it is one animated element on the whole page. Needs care not to read as an error state, so keep the halo brand-tinted and never coral or red.

Implementation notes

If one of these is chosen, the Angular version should follow these rules to stay inside the design system and the accessibility bar:

  • Colour comes from tokens only. These prototypes use --color-brand-soft, --p-pink-500, and --p-gold-500, which map to the registered accent-pink and accent-gold utilities. No new literals.
  • The layer is a sibling of the content with aria-hidden="true", pointer-events:none, and a negative z-index inside an isolate container, so it can never intercept a click or reach the accessibility tree.
  • Animate transform and opacity only. Never animate filter: blur(), width, or position, which force paint or layout on every frame.
  • Every animation must be disabled under prefers-reduced-motion: reduce, degrading to the still version rather than disappearing. The Simulate reduced motion button above shows the exact fallback.
  • Text contrast is measured against the composited result, not the flat token. If cards go translucent as in P1, verify body text still clears 4.5:1 over the brightest point of the background, and provide an opaque fallback for prefers-reduced-transparency.
  • Keep it to one ambient layer per page. P1 plus P4 together would double the compositing work for no added meaning.
