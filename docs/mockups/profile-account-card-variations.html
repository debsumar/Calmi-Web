Account detail card variations

Four treatments of the Personal information card, each paired with the matching Credentials and security card. No variant renders a secret, and every one fills its card height instead of leaving dead space at the bottom.

label left, value right

A quiet ledger with a fixed label column. Predictable and the easiest to extend; long values wrap in a narrow column and the layout reads as read-only.
