Rumi AI card variations

Six treatments of the same allowance: 28 of 30 conversations used, 2 remaining, renewing 01 Sep. Every card is boxed to the same height so you can see which ones fill the space instead of leaving a gap. Each carries one call to action, and the wording varies deliberately so you can pick a tone. The percentage always appears as text and each card has one meter with an accessible value.
